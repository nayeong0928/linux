### Serverless

- 개발자가 서버를 관리할 필요 없이 애플리케이션을 빌드하고 실행할 수 있도록 하는 클라우드 네이티브 개발 모델
- 사용자는 코드 작성 & 애플리케이션 배포에 집중
- 필요한 리소스를 동적으로 할당, 할당된 부분만 요금이 청구됨
- ex. AWS Lambda


### AWS Lambda

- Serverless 컴퓨팅 서비스
- AWS에서 서버 운영에 필요한 모든 인프라 관리
- 사용자는 코드를 입력해서 실행


### 특징
- 온디맨드 방식: 사용한 만큼만 비용 지불
- 자동 스케일링: 이벤트 횟수 & 리소스 사용량 기반
- 대부분의 AWS 서비스들과 통합하여 사용 가능
  - AWS CloudWatch와 자동으로 연결되어 있어서 모니터링/로깅 손쉽게 가능함
- 다양한 언어 지원: Node.js, Python, Java, C#, Golang 등
- 이벤트 기반 작업에 사용
